# Troubleshooting Guide

Common errors, symptoms, causes, and deterministic fixes when running `startup-idea-hunter-skill`.

---

## 1. Input Validation Errors (`error_type: "validation"`)

### Symptom: `clues[N].scores.<criterion> must be between 1 and 5`
- **Cause**: One of the five criteria (`frequency`, `pain_level`, `current_workaround`, `willingness_to_pay`, `market_size`) is missing, non-numeric, or outside the `[1.0, 5.0]` range.
- **Solution**: Ensure every clue object includes all five keys under `"scores"` with numeric values between `1` and `5`.

### Symptom: `Invalid need_tier '<value>'. Must be one of: pain, gratification, desire`
- **Cause**: An unsupported `need_tier` string was passed in the input JSON.
- **Solution**: Use `"pain"`, `"gratification"`, or `"desire"` (or omit `need_tier` so `scripts/score_clues.py` infers it automatically from the quote and pain/WTP scores).

### Symptom: `Duplicate clue id '<id>' at clues[N]`
- **Cause**: Two clues in the same input file share an identical `"id"`.
- **Solution**: Assign unique slug or alphanumeric IDs (`"clue-1"`, `"clue-2"`, etc.) to each clue.

---

## 2. Live Clue Harvesting Issues

### Symptom: Direct HTTP requests to `https://www.reddit.com/...` return HTTP 403 Blocked
- **Cause**: Reddit blocks unauthenticated script user-agents and datacenter IPs.
- **Solution**:
  1. Use the coding agent's built-in web search tool with `site:reddit.com` queries generated by `scripts/generate_queries.py`.
  2. To fetch full verbatim `selftext` and timestamps for specific Reddit post IDs without authentication blocks, query the Arctic Shift mirror:
     `https://arctic-shift.photon-reddit.com/api/posts/ids?ids=<id1>,<id2>`

### Symptom: Capterra or G2 pages return marketing copy instead of user complaints
- **Cause**: Landing on product overview pages (`/p/<id>/<Name>/`) instead of verified review pages or filtering only 5-star reviews.
- **Solution**: Target `/reviews` URLs and include `"Cons"`, `"clunky"`, `"manual"`, `"import"`, or `"formatting"` in the search query.

---

## 3. Evaluation & Maintenance Issues

### Symptom: `python3 scripts/run_evals.py --validate` fails
- **Cause**: Missing golden input files or malformed JSON block in `evals/startup-idea-hunter-skill.eval.md`.
- **Solution**: Verify that every path referenced in the `golden` array of `evals/startup-idea-hunter-skill.eval.md` exists relative to `evals/` and run `python3 scripts/run_evals.py --validate`.
